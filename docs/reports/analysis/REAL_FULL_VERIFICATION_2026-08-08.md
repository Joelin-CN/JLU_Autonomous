## 三、发现并修复的正式模式 Bug

### 生产构建白屏（P0）

**现象**：`npm run build:web` 后 Electron 以 `file://` 加载 `dist/index.html` 白屏，
DevTools 报 `file:///F:/assets/... ERR_FILE_NOT_FOUND`。

**根因**：`vite.config.ts` 未配置 `base`，默认 `/` → 构建产物引用绝对路径
`/assets/...`，`file://` 下解析到盘符根目录，资源全部 404。

**修复**：`frontend/vite.config.ts` 增加 `base: './'`，重建后资源变为相对路径，
正式模式正常渲染。打包发布形态（electron-builder 用 `loadFile`）同样受此问题影响，
此修复同时解决打包版白屏。
