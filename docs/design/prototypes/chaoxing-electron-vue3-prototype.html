前端建议

给 Electron + Vue3 的拆分方式

渲染层

  • 配置页做成一个 Job Form不要直接耦合脚本参数
  • 运行页做成实时面板日志、阶段、账号卡同步刷新
  • 课程页保留扫描快照支持从快照恢复

主进程

  • 统一管理 Python 子进程spawn / pause / stop / stdout
  • 持久化任务状态对应 `output/*.json`
  • IPC 只暴露明确动作`runJob`, `pauseJob`, `loadStatus`

高风险点

  • 不要让前端直接拼 shell 字符串统一由后端组装参数
  • 多账号并行要显式展示会话名`chaoxing-chrome-N`
  • batch-test 建议补一个纯 Python API 层别长期绑死在 PS1
